## 🌟 1. Project Vision & Architecture
**RENEW** is a modern, responsive, empathetic digital addiction recovery and wellness platform designed for individuals recovering from substance use disorders (alcohol, stimulants, opioids, and polysubstance dependencies).

The platform bridges the critical gap between inpatient rehabilitation and real-world daily life by pairing:
1. **The Patient Portal**: A compassionate, gamified, habit-rebuilding companion with 1-click **Craving SOS** intervention, guided somatic breathing, recovery streaks, reward points, and an empathetic AI companion.
2. **The Rehabilitation Centre / Counsellor Portal**: A clinical command centre for addiction specialists, psychologists, and case managers to monitor adherence, triage real-time distress alerts, prescribe custom activities, and generate compliance-ready clinical progress summaries.

### D. Craving SOS – PRIORITY EMERGENCY FEATURE
Clicking the prominent pulsing **Craving SOS** button launches a calming full-screen emergency sanctuary:
1. **Immediate Pause & Grounding:** Reassuring guidance reminding the patient that cravings peak in 10–15 minutes and naturally subside.
2. **Interactive Guided Box Breathing:** Expanding/contracting visual orb with countdown (Inhale 4s, Hold 4s, Exhale 4s, Rest 4s) accompanied by soothing audio tones.
3. **5-4-3-2-1 Sensory Grounding Checklist:** Interactive check-offs engaging sight, touch, sound, smell, and taste to pull awareness out of panic.
4. **Trigger Identification:** Categorizes the root driver (Stress/Work, HALT triggers: Hungry, Angry, Lonely, Tired, Social Environment, or Euphoric Recall).
5. **Personalized Coping Recommendations:** Actionable tips tailored to the selected trigger (e.g., mammalian dive reflex cold water splash).
6. **Engaging Distraction Mini-Game:** Cognitive word unscramble puzzle (PEACE, SERENITY, COURAGE, BREATHE) that diverts neural focus away from the craving.
7. **One-Tap Human Lifeline:**
   - 🩺 **Ping On-Call Clinician:** Instant high-priority alert to Dr. Sarah Mitchell's desk.
   - 🤝 **Call Recovery Buddy:** 1-tap call to peer supporter Liam Chen (68 days clean).
   - 📞 **National Crisis Line:** Samhsa 24/7 Helpline (`1-800-662-4357`) and `988` Lifeline clearly accessible.
8. **Post-Craving Relief Rating:** Patient rates relief (*Much Better*, *A Little Calmer*, *Still Intense*) which logs automatically into the **Craving Pattern Journal (Extra #2)** and awards `+40 reward points`.

## 🚀 6. How to Run the Platform

### Method 1: Instant Browser Execution (Zero Dependencies Needed)
Simply open `index.html` directly in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari:
```bash
# On Windows PowerShell:
Start-Process "index.html"
```
The entire application—including state persistence, interactive charts, Web Audio chimes, guided breathing animations, and demo accounts—runs seamlessly out of the box with zero npm installations required!

### Method 2: Modern React + Vite Development Server
If you prefer running within a standard Node.js / Vite build environment:
```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev

# 3. Open in browser:
http://localhost:3000
```
